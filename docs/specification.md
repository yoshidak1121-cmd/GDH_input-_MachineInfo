# NCサービス情報登録システム 仕様

## 実装スコープ（フロントエンドのみ版）

本実装はバックエンドAPIなしで動作するフロントエンドのみの完全実装です。
データはブラウザの `localStorage` に保存されます。

---

## 実装済み機能

### 画面

| 画面 | 機能 |
|------|------|
| S01 一覧・検索 | 全登録データの表示・フィルタリング（NCシリアル番号/型名/ステータス/エンドユーザ）・編集・契約追加 |
| S02 新規登録開始 | NCシリアル番号入力・重複チェック |
| S03 基本情報（Step1） | NC情報・機械情報・NC販売情報の入力。NCシステム型名選択で仕様属性を自動表示 |
| S04 輸出・設置（Step2） | 機械輸出情報・設置情報の入力。日付順序警告を表示 |
| S05 契約情報（Step3） | 契約行の追加・削除・コピー。契約終了日を開始日＋期間から自動計算 |
| S06 確認（Step4） | 全入力内容の確認。バリデーションエラーがある場合は登録ボタン無効化 |
| S07 完了 | 登録完了。新規登録・一覧戻り・同NC契約追加ボタン |
| S08 マスタ簡易登録ダイアログ | NCシステム型名/MTBマスタへの簡易追加 |
| S09 下書き一覧 | 入力途中データの再開・削除 |
| M01-M07 マスタ管理 | 全マスタの有効化/無効化 |

### バリデーション

**エラー（保存不可）:**
- NCシリアル番号: 必須・重複不可
- 契約行がある場合: 契約タイプ・契約期間（1以上の整数）・契約開始日は必須
- メモ欄: 300文字以内

**警告（保存可能）:**
- 機械輸出日 < NC販売日
- 設置日 < 機械輸出日
- 契約開始日 < 設置日
- 同一NC内での契約番号重複

### 下書き保存

- NCシリアル番号のみでも下書き保存可能
- ウィザード各ステップに「💾 下書き保存」ボタン設置
- 下書きは S09 下書き一覧から再開・削除可能

### マスタ管理

- 各マスタの有効化/無効化（物理削除なし）
- 無効化済みマスタが既存データで使用されている場合、「表示名（無効）」として表示
- NCシステム型名・MTBマスタは簡易登録ダイアログから新規追加可能

### 契約情報

- 1つのNCに対して複数の契約情報を登録可能
- 契約行の追加・削除・コピー
- 契約終了日は `契約開始日 + 契約期間（月数） - 1日` で自動計算（DB保存なし）
- 契約追加時のデフォルト値: ご契約者=MTB、契約タイプ=FULL、期間=24ヶ月、開始日=設置日

## アーキテクチャ

```
index.html              # SPA HTML（全画面テンプレート）
css/style.css           # スタイルシート
js/app.js               # メインアプリ（ルーティング・画面管理・デモデータ）
js/state.js             # 状態管理（localStorage + マスタオーバーライド）
js/master.js            # マスタデータ読込・選択肢生成
js/contracts.js         # 契約テーブル管理
js/validation.js        # 入力バリデーション
data/*.json             # マスタデータ（JSONファイル）
db/schema.sql           # SQL Server DDL
db/seed.sql             # 初期マスタ・サンプルデータ
docs/api_spec.md        # 将来のREST API仕様書
```

## 既知の制限と将来の課題

- **認証なし**: 現在はシングルユーザー想定。将来的に Microsoft Entra ID 連携を想定
- **localStorage制限**: ブラウザのストレージ制限（通常5-10MB）に達した場合にデータ保存が失敗する可能性
- **バックエンドAPI**: 本番環境では SQL Server + REST API（FastAPI/ASP.NET Core）への移行が必要
- **マスタ管理**: NCシステム型名とMTB以外のマスタへの新規追加機能は未実装（SQL直接登録が必要）
- **CSV出力**: 一覧からのCSVエクスポート機能は未実装
- **ユーザー権限管理**: 全ユーザーが全データを閲覧・編集可能
